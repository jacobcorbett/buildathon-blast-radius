# Project workflow

- Follow the official track and scorer rules linked from README.md.
- Use small, reversible, scoped commits with descriptive prefixes such as chore:, feat:, fix: or docs:.
- Stage explicit paths and preserve unrelated changes. Check the diff and run relevant validation before publishing.
- Before opening a pull request, run the local-pr-autoreview skill and keep the PR focused.
- Keep downloaded kits, sample labels, generated data and credentials out of the public repository.
